# SEO tools

Tools for winning search traffic for serenitybrides.com, a bridal boutique in Colchester, Essex, against named competitors.

## Competition

**Competitor**:
A named rival site whose rankings set our targets. The primary competitor is theweddingshop.uk.
_Avoid_: rival, other site

**Win**:
For a keyword where the competitor is #1 organically, we are #1; for a keyword where the competitor appears in the map pack, we appear in the map pack too.
_Avoid_: ranking well, beating them (unqualified)

**Win set**:
The keywords where a win is defined: the competitor is #1 organically or appears in the map pack.

**Secondary target**:
A keyword target outside the win set; the aim is to outrank the competitor, ranked after the win set by search volume.
_Avoid_: nice-to-have, long tail

**Map pack**:
The Google local results block (map plus business listings) shown above or among organic results for local searches.
_Avoid_: local pack, 3-pack, Google Maps results

**Phase**:
The order in which product lines are worked: phase 1 is bridal; phase 2 is mother of the bride and bridesmaids.

## Keywords and pages

**Product line**:
One of the boutique's ranges of customer: bridal, bridesmaids, mother of the bride (MOB).
_Avoid_: category, department

**Keyword target**:
A set of close-variant keywords plus exactly one target page meant to rank for them, within one product line and phase.
_Avoid_: cluster, topic, keyword group, improve

**Close variants**:
Keywords Google treats as the same search (spellings, word order, singular/plural); they share one search volume figure, which is counted once.
In on-page checks a match also allows up to 2 extra words between the keyword's words ("Wedding dress & bridal shop in Colchester" holds "wedding dress shop Colchester"); anchor matching stays strict.
_Avoid_: duplicates, synonyms

**Target page**:
The one page (live or planned) that a keyword target points at; no other page of ours competes for those keywords.
_Avoid_: landing page, destination

**Supporting page**:
A page of ours that links to a target page to strengthen it, rather than competing with it.
_Avoid_: source page, link-from page

**Topic**:
The wider subject a hub page covers (for example short wedding dresses under bridal); a topic may hold several keyword targets.
_Avoid_: theme, cluster

**Style tag**:
An owner-approved label on a dress for a shopper-facing style (for example lace, short), used to group dresses into a style page; distinct from designer.
_Avoid_: facet, attribute, filter

**Trail**:
The breadcrumb links on a dress page, from the product line page through the dress's designer page, each named "{type} wedding dresses".
_Avoid_: back-link, breadcrumb (in conversation, prefer "trail")

**Last stock**:
A dress sold off the peg because it is discontinued; a property of the individual dress. A designer range is last stock only when every one of its dresses is; one or a few off-the-peg dresses never make the range or designer discontinued.
_Avoid_: discontinued range (when only some dresses are off the peg), OTP range

**Anchor**:
The visible link text of an internal link pointing at a target page.
_Avoid_: link text, anchor text (in code and docs, prefer "anchor")

**Contextual link**:
An internal link placed in a page's main body copy, as opposed to navigation, header, footer or trail links.
_Avoid_: in-content link, body link

**Template link**:
A link generated by a page template, so it appears on every page of that type with the same anchor (for example the "Also in:" line on dress pages); counted apart from links written into page copy.
_Avoid_: sitewide link, boilerplate link

**Anchor conflict**:
An anchor on a link to one target page that contains a keyword belonging to a different keyword target, pushing that keyword at the wrong page.
_Avoid_: wrong anchor (that means a live anchor differing from the planned one)

**Link map**:
The view of every keyword target with its target page, the contextual links pointing at it, their anchors and plan status, and what remains to do.
_Avoid_: link plan (the plan is the list of proposed links; the map is the whole picture)

## Reviews

**Decaying page**:
A page whose clicks in the last 28 data days fell by at least 30% and at least 5 clicks against either the previous 28 days or the same 28 days a year earlier (364 days back). "No data" when Search Console has no rows for that window (the property's data starts 2026-09-13).

**Digest**:
Weekly review page (UI only) built from Search Console data only; no paid calls.

**Low-CTR query**:
A non-brand query on page 1 (average position below 8) with at least 100 impressions whose click-through rate over the last 28 data days is under half the expected CTR for its position (1→28%, 2→15%, 3→10%, 4→7%, 5→5%, 6→4%, 7→3%); clicks missed = expected clicks − actual clicks. Review signal only.

**Page-2 query**:
A query with average position 8–20 over the last 28 data days and at least 10 impressions; tagged on-target when it is a close variant of the page's keyword target, else off-target (review signal only).
